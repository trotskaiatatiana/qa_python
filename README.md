# Тестирование BooksCollector
# В проекте реализованы автотесты для класса BooksCollector с использованием библиотеки pytest:

# Добавление новых книг: 1) проверяется добавление двух книг в словарь books_genre; 2) проверяется, что книга с пустым названием или названием длиннее 40 символов не добавляется.

# Установка жанра книги: проверяется установка жанра для добавленной книги.

# Получение книг определённого жанра: 1) проверяется получение списка книг с указанным жанром; 2) для разных жанров используется параметризация.

# Получение словаря книг и жанров: проверяется корректность содержимого словаря books_genre.

# Получение книг, подходящих детям: проверяется, что в список попадают книги без возрастного рейтинга.

# Добавление книги в избранное: 1) проверяется добавление книги в список favorites; 2) проверяется, что одну и ту же книгу нельзя добавить в избранное повторно.

# Удаление книги из избранного: проверяется удаление книги из списка favorites.

# Получение списка избранных книг: проверяется корректность списка избранных книг.
